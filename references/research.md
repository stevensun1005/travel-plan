# 查价、排程与资料覆盖

## 报价要记录什么

| 项目 | 必要信息 |
| --- | --- |
| 航班 | 查价日，人数，往返/单程全程总价，机场、当地日期时刻、中转与总时长、舱等、行李、退改缺口、币种、来源 |
| 酒店 | 入住退房、晚数、人数/房间、房型，全住期总额、税/强制费、停车早餐另收与否、退款、来源 |
| 租车 | 指定车型/同级、座位、变速箱、年龄驾照资格、取还时刻、完整总价、青年费、保障/自付、责任险、税、里程、交车费和退款 |
| 活动 | 日期与目标场次、营业/休息日、预约窗口、票含什么、交通和退改；目标场次不等于已取得余位 |

价格状态用：已预订、指定条件查价记录、搜索页记录、官方常规价、预算估算、尚无报价、虚构演示。网页可访问不代表库存已核实，一次查价不叫持续实时价格。

用户指定Expedia等平台时遵循来源偏好；尽量核到完整往返/开口程汇总，不将单程选中价、其他日期或同城往返价冒充当前完整行程。涉及多城性价比、报价适用条件与景点详情时读 [多城市选择与景点详情](multi-city.md)。

具体门店与车型优先于品牌通用年龄规则。规则冲突就说明并继续取得门店确认或该年龄结算记录。加拿大完整驾照、多年驾龄不自动免青年费，双座敞篷也不天然更便宜。改变日期或租期需重新报价；48小时与多一小时可能不同计费。汇率是预算假设，不是结算承诺。

## 限制与特殊日期

可以正常行走上下车但不登山：保留正常参观、驾车和车览，山顶步道可替换为外围观景，并明确不是登顶。浮潜与脚蹼使用依本人已有康复建议、现场指导及海况，不给医学许可保证。

冬季北岸等风险核对当地管理机构资料；不能用「上午通常平静」保证冬季能下水。区分到访海湾与在那里浮潜：岸边到访可以保留，下水移到合适地点。末日浮潜要核对实际航班和补做窗口，不与水肺潜水混为一谈。

按周几、周休、节假日、特别营业、预约、晚秀与回程核对日程。往年烟花公告不是本年度确认，常规大秀不是跨年特别节目。冲突的晚餐、文化村与游船只能是替换方案。

## 旧攻略项目覆盖

提取所有地点、体验、餐厅和备选，去重后区分必去、在该地点的替代玩法、有空才做。三个牧场tour备选不等于全买。按最新要求取消冲浪、替代hiking，并展示覆盖表：原项目 → 日期/替代/取消/备选 → 解释。

不能静默遗漏。五晚不变但项目增加时，说明紧凑度、迷宫等排队可选项、错过的表演、预算上涨，不假装与原资料建议的每项整天等价。私人行程、健康描述、驾照信息和订单不作为公开demo fixture。
